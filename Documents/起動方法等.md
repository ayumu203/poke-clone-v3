# 各種起動方法

## コンテナの起動

```bash
# コンテナをビルドして起動
docker compose up -d --build
# ログを確認
docker compose logs -f app
```

## コンテナの停止・削除

```bash
# コンテナの停止
docker compose stop

# コンテナの停止と削除
docker compose down

# コンテナ、ボリューム、ネットワークをすべて削除（データも削除される）
docker compose down -v
```

## APIの確認

以下のURLでAPIのドキュメントにアクセスできます:

- <http://localhost:5000/swagger/index.html>

### 認証不要のエンドポイント

```bash
# 全件取得
curl -X GET http://localhost:5000/api/pokemon/   -H "Accept: application/json"
# レスポンスを整形して表示
curl -X GET http://localhost:5000/api/pokemon/1 | jq .
# レスポンスを整形して表示
curl -X GET http://localhost:5000/api/moves/1 | jq .
```

### 認証が必要なエンドポイント

> [!IMPORTANT]
> このプロジェクトは **Firebase Authentication** を使用しています。

#### Firebase トークンの取得方法

1. **フロントエンドを起動**:

```bash
cd Client
pnpm dev
```

2. **ブラウザでログイン**:
   - `http://localhost:3000/login` にアクセス
   - 「ゲストとしてプレイ」ボタンをクリック（匿名ログイン）

3. **トークンを取得**:
   - ブラウザのコンソール (F12) を開く
   - 以下のコマンドを実行:

```javascript
// Firebase ID トークンを取得
import { getAuth } from 'firebase/auth';
const token = await getAuth().currentUser.getIdToken();
console.log('Token:', token);
// トークンをコピー
copy(token);
```

4. **ターミナルでトークンを設定**:

```bash
# 取得したトークンを環境変数に設定
TOKEN="paste_your_firebase_token_here"

# トークンの確認
echo "Token obtained: ${TOKEN:0:50}..."
```

#### トークンを使用したAPI呼び出し

```bash
# プレイヤー情報の登録・更新
curl -X POST http://localhost:5000/api/player/me \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "プレイヤー名",
    "iconUrl": "https://example.com/icon.png"
  }' | jq .

# プレイヤー情報の取得
curl -X GET http://localhost:5000/api/player/me \
  -H "Authorization: Bearer $TOKEN" \
  -H "Accept: application/json" | jq .

# パーティ情報の取得
curl -X GET http://localhost:5000/api/party \
  -H "Authorization: Bearer $TOKEN" | jq .
```

#### トークンの有効期限

- **有効期限**: 1時間
- トークンの有効期限が切れた場合は、ブラウザのコンソールで再度 `getIdToken(true)` を実行してください

```javascript
// トークンを強制的に更新
const freshToken = await getAuth().currentUser.getIdToken(true);
console.log('Fresh Token:', freshToken);
copy(freshToken);
```
